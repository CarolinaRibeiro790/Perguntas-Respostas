## 🚀 Sobre o Projeto
Este projeto foi desenvolvido como parte de um treinamento prático em Node.js durante aulas na faculdade. Trata-se de um sistema simples para coleta de dúvidas por meio de um formulário, utilizando tecnologias de backend, banco de dados e renderização de templates.

## 🛠️ Tecnologias Utilizadas
<li>Node.js: Para construir o servidor backend.
<li>Express: Framework para gerenciar rotas e requisições HTTP.
<li>MySQL: Banco de dados relacional para armazenar as dúvidas.
<li>EJS: Template engine para renderização dinâmica no frontend.

## 📝 Funcionalidades Principais
<li>Coleta de dúvidas por meio de um formulário.
<li>Armazenamento das dúvidas em um banco de dados MySQL.
<li>Renderização das dúvidas cadastradas na interface.

## 📦 Como Rodar o Projeto: 
npm i (instala as dependências) <br>
npm run dev (inicia o servidor do projeto) <br>
1.  Antes é preciso criar um banco com o nome projetopratico <br>
2. A minha porta do banco está configurada na 3307, se estiver em outra porta o seu banco alterar no arquivo database.js, dentro da pasta database.
